# AGENTS.md — Browserly Maintenance & Architecture Guide

Browserly (`browserly.maoxunxing.com`) is a zero-dependency, first-party verified bilingual comparison matrix and dossier directory of browser-driving AI agents, running on **Cloudflare Workers** (`browseboard`) with **Cloudflare Workers Static Assets**.

## 1. Repository Layout

```text
src/
  data/
    seed.json          # Single source of truth: agent rows, verification dates, sources, changelog, exclusions
    stories.json       # Curated Chinese editorial verdicts & deep-dive breakdowns for /agent/:id
    catalog.js         # Data normalizer, LOGO_MAP, pastel palette, /api/agents & /llms.txt serializers
    recommender.js     # Deterministic 6-axis solution selection engine powering /api/recommend and the Web Finder
  i18n/
    dict.js            # EN & ZH UI copy, enum label helpers, and semantic badge tone rules
  styles/
    app.css            # Complete editorial design system, responsive grids, and subtle GPU micro-animations
  client/
    app.js             # Zero-dependency client runtime (search, presets, filters, cards/table, compare modal, 30s Solution Finder, demo drawer, instant EN/ZH toggle)
  server/
    icons.js           # Inline SVG icon helpers
    skill.js           # Bilingual momo-browserly-advisor Agent Skill generator (/SKILL.md & /SKILL.zh-CN.md) with auto-synced offline snapshot
    components.js      # HTML escaper, document shell, unified header, agent cards, footers, WeChat block
    pages.js           # SSR renderers for /, /agent/:id, /about, /sponsor, and 404
    worker.js          # Cloudflare Worker fetch router (/api/agents, /api/recommend, /SKILL.md, /llms.txt, SSR) & locale negotiation
skills/
  momo-browserly-advisor/   # Auto-synced installable Agent Skill (SKILL.md, SKILL.zh-CN.md, eval-cases.json) for `npx skills add XingMXTeam/browsely`
scripts/
  build.mjs            # Compiles & minifies CSS, client JS, pkg/worker.js, and regenerates assets_current/manifest_raw.json
  dev.mjs              # Local HTTP preview server executing compiled pkg/worker.js against assets_current/ on port 8787
  verify.mjs           # Automated test suite (630+ assertions across schema, routes, bilingual HTML, manifest hashes, and size budgets)
assets_current/
  assets/              # Content-hashed app.<hash>.css and app.<hash>.js generated by scripts/build.mjs
  fonts/               # Self-hosted Bricolage Grotesque variable WOFF2
  logos/               # Local agent logos (/logos/<id>.png|svg|jpg)
  posters/             # Local diagram/poster assets (/posters/...)
  browseboard.svg      # Brand mark
  icon.svg             # Favicon
  wechat-qr.jpg        # WeChat contact QR image
  manifest_raw.json    # Auto-generated static asset manifest consumed by upload_and_version.py
pkg/
  worker.js            # Auto-generated single-file ES Module Cloudflare Worker bundle
wrangler.jsonc         # Standard Cloudflare Wrangler configuration
upload_and_version.py  # Direct Cloudflare API asset uploader & Worker version deployer
```

## 2. Standard Commands

- **Build & Verify (Run after every change):**
  ```bash
  npm run check
  ```
- **Local Preview Server (`http://127.0.0.1:8787`):**
  ```bash
  npm run dev
  ```
- **Deploy to Cloudflare Workers:**
  ```bash
  npm run deploy
  # or via Wrangler CLI:
  npx wrangler deploy
  ```

## 3. How to Add or Update an Agent Row

1. **Add Logo:** Place the logo in `assets_current/logos/<id>.svg` (or `.png` / `.jpg`) and register `"<id>": "/logos/<id>.<ext>"` in `LOGO_MAP` inside `src/data/catalog.js`.
2. **Update `src/data/seed.json`:**
   - Add or update the entry in `entries[]` with required fields: `id`, `name`, `org`, `homepage`, `github`, `docs`, `license`, `perception` (`dom` | `vision` | `hybrid` | `unknown`), `perception_note`, `hosting` (`self-host` | `cloud` | `both`), `hosting_note`, `mcp` (`yes` | `partial` | `no` | `unknown`), `mcp_note`, `auth_model`, `auth_model_detail`, `anti_bot`, `anti_bot_badge`, `pricing_summary`, `pricing_badge`, `last_checked` (`YYYY-MM-DD`), `sources` (non-empty array of `https://` URLs), and optional `video` / `video_poster` / `video_kind`.
   - Update ` EXPECTED` row count check in `src/data/catalog.js` and `scripts/verify.mjs` if the total active agent count changes from `17`.
   - Record the verification pass in `meta.as_of` and `changelog_seed[]`.
3. **Optional Editorial Verdict:** Add a corresponding entry in `src/data/stories.json` with `verdict`, `perception`, `mcp`, `credentials`, `antiBot`, `pricing`, `credentialLabel`, and `related`.
4. **Build & Verify:** Run `npm run check` to rebuild `pkg/worker.js` and `assets_current/manifest_raw.json` and confirm all checks pass.

## 4. Core Design & Data Principles

- **Epistemic Honesty:** Never guess unverified capabilities or prices; mark them `unknown` (rendered with a dashed border).
- **Zero External Runtime Dependencies:** Keep `src/` and `scripts/` dependency-free so builds and tests run instantaneously in any Node.js environment.
- **Performance Budgets (enforced by `scripts/verify.mjs`):**
  - `pkg/worker.js` < 190 KB raw
  - CSS bundle < 54 KB raw / < 10.5 KB gzip
  - Client JS bundle < 72 KB raw / < 21 KB gzip
  - Homepage SSR HTML < 148 KB raw / < 25 KB gzip
